# 이터널 리턴 밸런스 게임
![스크린샷 2025-05-12 123004](https://github.com/user-attachments/assets/b4d1526a-955a-4714-92cc-1601d3d5e215)
이터널 리턴 밸런스 게임은 게임 [이터널 리턴](https://playeternalreturn.com/main?hl=ko-KR)에서 벌어지는 다양한 상황을 가정하여 밸런스 게임을 진행합니다.

## :question: 밸런스 게임이 뭔가요?
밸런스게임은 두 가지 선택지 중 하나만 고르는 게임입니다.

## :joystick: 게임 방법
![image](https://github.com/user-attachments/assets/1d8d521d-a3ad-4716-b5e0-e5034b5de443)

1. 인게임의 특정 상황에 대한 설명입니다.
2. 상황에 대한 두 가지 선택지로, 플레이어가 생각하기에 적절한 선택지를 고르면 됩니다.
3. 다른 질문을 보고 싶다면, 해당 버튼을 클릭하여 여러 질문을 랜덤으로 가져올 수 있습니다.

## :pencil: 질문 생성 방법
![스크린샷 2025-05-12 123626](https://github.com/user-attachments/assets/7f7ab8ba-3658-47e2-97bc-bf7e2d95e396)

밸런스 게임을 만들고 싶다면 질문을 직접 생성할 수 있습니다.  

질문란과 선택지 A, B를 모두 채운 후, "만들기" 버튼을 클릭하면 간단하게 질문을 작성할 수 있습니다.  
질문을 작성할 때, 안내사항은 샬럿을 통해 확인해주세요.

단, 욕설과 같은 말은 사용할 수 없으니 주의해주세요.
